# Syncthing Quick Setup Guide (For Ron & Nick)

Syncthing lets you sync your `SuperStationOne\games` folder directly between your PCs over the internet or local network without third-party storage fees or file size limits.

## 1. Installation
- Download **SyncTrayzor** (Windows GUI for Syncthing) from:
  https://github.com/canton7/SyncTrayzor/releases
- Install and run it on both PCs.

## 2. Connect Your PCs
1. In SyncTrayzor, click **Actions** -> **Show ID**.
2. Share the 50-character Device ID with each other.
3. On the other PC, click **Add Remote Device** and paste the ID.
4. Accept the connection prompt on both sides.

## 3. Share the Games Folder
1. Under **Folders**, click **Add Folder**.
2. **Folder Label:** `SuperStationOne Games`
3. **Folder Path:** `O:\SuperStationOne\games`
4. Under the **Sharing** tab, check each other's device.
5. On the receiving PC, approve the share and set the path to the local `SuperStationOne\games` directory.

Any game you or Nick add will automatically sync in the background!
